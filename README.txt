THE LITTLE UNIVERSE OF US - MOBILE RESPONSIVE UPDATE

Files:
- index.html
- style.css
- script.js

How to use:
1. Back up your current website folder first.
2. Copy these three files into your website folder and replace the old versions.
3. Keep your existing images folder (if you have one) in the same website folder.
4. Start Apache in XAMPP.
5. Open http://localhost/website/ in Chrome.
6. Test mobile layout with F12, then Ctrl + Shift + M.

The mobile navigation stays at the top. On small screens, tap the hamburger icon
(three lines) to open the navigation links. Selecting a link closes the menu.

Note: The HTML references images/photo1.jpg through images/photo4.jpg. Keep your
existing images folder alongside these files so those photos continue to appear.
